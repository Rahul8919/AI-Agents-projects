# Multi-Agent AI Research System

## Overview

This project demonstrates a **multi-agent AI research pipeline** built using the **OpenAI Agents SDK**.
The system coordinates multiple specialized AI agents to perform structured market research and generate a comprehensive report.

Instead of relying on a single AI model, the system divides the task among multiple agents:

1. **Research Agent** – gathers information from the web
2. **Analyst Agent** – analyzes the research findings
3. **Writer Agent** – generates a professional research report

This architecture improves reasoning, structure, and reliability of AI-generated insights.

---

# System Architecture

User Query
↓
Research Agent (Web Search)
↓
Analyst Agent (Insight Extraction)
↓
Writer Agent (Report Generation)
↓
Final Research Report

---

# Agents in the System

## Research Agent

The Research Agent is responsible for collecting relevant information from the internet using the **Tavily Search API**.

Responsibilities:

* Perform web searches
* Retrieve relevant news and data
* Summarize findings in bullet points

Tool Used:

* Tavily Web Search API

---

## Analyst Agent

The Analyst Agent analyzes the research results generated by the Research Agent.

Responsibilities:

* Identify trends
* Detect risks
* Extract key insights

Output:

* A concise analysis of the research findings.

---

## Writer Agent

The Writer Agent synthesizes all information into a structured research report.

Responsibilities:

* Generate an executive summary
* Produce a detailed markdown report
* Suggest follow-up research questions

Output Structure:

* Executive Summary
* Detailed Research Report
* Follow-up Research Questions
