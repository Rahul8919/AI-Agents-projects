# ✈️ AI Travel Planner Agent (LangGraph + OpenAI + Amadeus)

An **Agentic AI travel assistant** built using **LangGraph, OpenAI LLMs, Tavily Search, and Amadeus Travel APIs**.
The system uses an **AI agent with tool-calling capabilities** to search for flights, hotels, and travel information in real time.

This project demonstrates how **LLM agents orchestrate external APIs using LangGraph workflows**.

---

# 🚀 Features

✅ Agentic AI workflow using **LangGraph**
✅ Real-time **flight search** using Amadeus API
✅ Real-time **hotel search** using Amadeus API
✅ **Web research tool** using Tavily Search
✅ **Dynamic tool calling** by the AI agent
✅ **State management** with LangGraph
✅ Travel planning assistant powered by **OpenAI models**

---

# 🧠 Architecture

The agent follows a **ReAct-style workflow**.

User Query
↓
LLM Agent
↓
Decides whether tools are required
↓
Tool Execution Node
↓
Tool Result returned to Agent
↓
Final Answer generated by LLM

LangGraph Workflow:

Agent Node → Tool Node → Agent Node → END

# 🧰 Tools Implemented

## 1️⃣ Flight Search Tool

Searches live flight offers using the **Amadeus Flight Offers API**.

Parameters:

* Origin Airport Code
* Destination Airport Code
* Departure Date
* Return Date (optional)
* Travel Class
* Adults

Example Output:

Airline | Departure → Arrival | Duration | Price

---

## 2️⃣ Hotel Search Tool

Uses **Amadeus Hotel Search API** to find available hotels.

Steps:

1. Find hotels in a city
2. Extract hotel IDs
3. Search hotel offers
4. Return hotel name and price

Example Output:

Hotel: Hilton Paris Opera – 320 EUR
Hotel: Novotel Paris Centre – 210 EUR

---

## 3️⃣ Web Search Tool

Uses **Tavily Search API** to gather travel information such as:

* Latest travel news
* Tourism advice
* Safety updates
* Travel tips

---

## 4️⃣ Current Date Tool

Returns the current date to help the agent calculate travel dates.

Example:

```
2026-03-15
```

# 🏗️ Agent Workflow

State is managed using **LangGraph StateGraph**.

AgentState stores conversation history:

```
class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], operator.add]
```

The agent decides dynamically whether to:

* Call a tool
* Generate a final response
