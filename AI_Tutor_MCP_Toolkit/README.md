# MCP AI Tutor Agent

## Overview
This project implements an AI Tutor Agent using the Model Context Protocol (MCP).  
The agent interacts with an MCP server to access tools and provide intelligent responses for learning programming and AI concepts.

## Architecture

User Query → AI Tutor Agent → MCP Server → Tools → Response

## Tech Stack
- Python
- OpenAI API
- MCP Protocol
- Async Programming

## Files
- AI_Tutor_agent_client.py → Agent that communicates with MCP server
- Building_an_MCP_server.py → MCP server implementation
- requirements.txt → Project dependencies

## Key Features
- Tool-enabled AI agent
- MCP server integration
- Modular architecture
- Extensible tool framework
